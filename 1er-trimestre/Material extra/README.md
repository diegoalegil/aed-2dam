# Material extra para practicar

Simulacros y ejercicios de repaso de los exámenes del primer trimestre. Cada proyecto trae su README con el enunciado. Los que tienen `calcular_nota.py` sacan la nota igual que en el examen.

| Carpeta | Examen | Qué es |
| --- | --- | --- |
| `arcade-lab-dao` | 2 (JDBC) | `AbstractDao` con JDBC y SQLite, en 90 minutos |
| `padre-variantes` | 2 (JDBC) | Cinco versiones de la clase padre `AbstractDao`, cada una con sus tests |
| `hotel-reservas` | 2 (JDBC) | Simulacro final: reservas de hotel con JDBC y SQLite |
| `banco-orm` | 3 (ORM) | Banco con JPA/Hibernate y SQLite, por niveles |
| `autoescuela-alumnado` | 3 (ORM) | Simulacro de la autoescuela con JPA |
| `cinefest-alumnado-alternativa` | 3 (ORM) | Otra versión de CineFest para repasar |
